KadrMarketКонфиденциальность

Фотографии обрабатываются на вашем устройстве

Редактор KadrMarket не загружает выбранные изображения на сервер. Декодирование, Canvas, сжатие и ZIP выполняются локально в браузере.

Какие данные используются

Бесплатный редактор работает без регистрации. Настройки brand-kit сохраняются только в localStorage устройства. При покупке Pro покупатель самостоятельно отправляет email с order ID; для выдачи сохраняются адрес, номер заказа, сумма, статус и время операции.

Для чего нужен email

Email используется для проверки заказа, отправки лицензии, Pro-архива и ответа на входящий вопрос. Адреса не продаются и не используются для холодной рекламы.

Хостинг

Публичные страницы размещены на GitHub Pages. GitHub может обрабатывать технические журналы посещений, включая IP-адрес, согласно собственной политике конфиденциальности.

Удаление данных

Запрос на удаление данных заказа можно отправить на undemoon799@gmail.com. Финансовая запись может сохраняться в пределах срока, необходимого для учёта и разрешения споров.

Безопасность

Не отправляйте номер карты, CVV, PIN, пароль банка или коды подтверждения. Для оплаты KadrMarket сообщает только реквизиты получения перевода по СБП.
